## Privacy and interpretation

Only UI pixels are published. Passwords, tokens, email addresses, session dumps, network traces and database URLs are absent from these selected assets. Synthetic test names/run labels remain visible so the examples cannot be mistaken for real client outcomes or advisor endorsements. No raw audit evidence is included.

The booking-confirmation image shows a request accepted as pending. Confirmation/completion screenshots show separate moments in that recorded lifecycle. The community post/comment shown here was removed through its owners' application controls after the audit; it is a historical workflow capture, not a promise that the post remains in the live feed. The review is explicitly synthetic. Dashboard crops focus on real overview counters rather than empty upcoming lists.

The original unreliable mobile review screenshot is excluded. The included mobile image is a fresh homepage viewport and does not resolve that separate review-layout coverage gap. Current public community listing content was omitted to avoid republishing non-synthetic financial content. Every requested feature has a representative real screenshot, but authenticated views were not recaptured in this documentation session.
